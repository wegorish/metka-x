# metka-x

Лендинг магазина адресников для питомцев «Метка».
Статический сайт на HTML, CSS и JavaScript без сборки и зависимостей — публикуется на GitHub Pages как есть.

## Структура

```
index.html          разметка страницы
css/styles.css      стили: десктоп (макет 1920 px) и адаптив (1399 / 1199 / 899 / 599 px)
js/main.js          бургер-меню и ссылки-заглушки
js/configurator.js  конструктор адресника: форма, цвет, текст с тиснением
assets/fonts/       Golos Text (woff2, self-hosted)
assets/img/         фотографии (webp); assets/img/tags — 9 превью адресников (форма × цвет)
assets/icons/       иконки и логотипы (svg); logo-mark.svg — знак из логотипа шапки, для футера
```

Все пути относительные, поэтому сайт работает и из корня домена, и из подпапки `/metka-x/`.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → ветка `main`, папка `/ (root)`.
Адрес сайта: https://wegorish.github.io/metka-x/

## Что пока не доделано

- Конструктор: вместо цены стоит «[ЦЕНА]», кнопка «Заказать» ведёт к контактам. Оформление заказа пока не подключено.
- Кнопка «Смотреть ещё» в галерее не активна.
- Контакты в футере тестовые; ссылки Telegram, MAX, Direct и Threads — заглушки.
- Плейсхолдеры в квадратных скобках в блоках «Оплата и доставка» и в футере ждут настоящих данных.

## Как устроен конструктор

- Превью лежат в `assets/img/tags/<форма>-<цвет>.webp`, формы: `circle`, `heart`, `bone`, цвета: `silver`, `gold`, `rose`.
- Новая форма или цвет: добавить файл, радио-кнопку в `index.html` и правило площадки под текст (`--tw`, `--ty`, `--fs`) в блоке `.config__stage[data-shape=…]` в `css/styles.css`.
- Текст показывается заглавными буквами, максимум 12 символов; если надпись не помещается на адреснике, шрифт уменьшается автоматически.
