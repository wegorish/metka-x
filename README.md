# metka-x

Лендинг магазина адресников для питомцев «Метка».
Статический сайт на HTML, CSS и JavaScript без сборки и зависимостей — публикуется на GitHub Pages как есть.

## Структура

```
index.html          разметка страницы
css/styles.css      стили: десктоп (макет 1920 px) и адаптив (1399 / 1199 / 899 / 599 px)
js/main.js          бургер-меню и ссылки-заглушки
js/configurator.js  конструктор адресника: форма, цвет, текст с тиснением, цена по форме
js/order.js         форма заказа (выезжает сверху) и уведомление «Заказ принят!»
assets/fonts/       Golos Text (woff2, self-hosted)
assets/img/         фотографии (webp); assets/img/tags — 9 превью адресников (форма × цвет)
assets/icons/       иконки и логотипы (svg); logo-mark.svg — знак из логотипа шапки, для футера
```

Все пути относительные, поэтому сайт работает и из корня домена, и из подпапки `/metka-x/`.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → ветка `main`, папка `/ (root)`.
Адрес сайта: https://wegorish.github.io/metka-x/

## Что пока не доделано

- Форма заказа тестовая: проверяет поля и показывает уведомление, но заявка никуда не отправляется. Место для подключения приёма заказов отмечено комментарием в `js/order.js`.
- В конструкторе нет выбора размера, поэтому в чекаут формы заказа он не попадает (только форма, цвет и текст).
- Контакты в футере тестовые; ссылки Telegram, MAX и «Direct + Threads» — заглушки.
- Плейсхолдеры в квадратных скобках в блоках «Оплата и доставка» и в футере ждут настоящих данных.

## Как устроен конструктор

- Превью лежат в `assets/img/tags/<форма>-<цвет>.webp`, формы: `circle`, `heart`, `bone`, цвета: `silver`, `gold`, `rose`.
- Новая форма или цвет: добавить файл, радио-кнопку в `index.html` и правило площадки под текст (`--tw`, `--ty`, `--fs`) в блоке `.config__stage[data-shape=…]` в `css/styles.css`.
- Текст показывается заглавными буквами, максимум 16 символов (`maxlength` у поля `#tag-text`).
- Размер надписи зависит от числа букв: одна буква самая крупная, с каждой новой шрифт уменьшается (границы — `MAX_FONT_PX` и `MIN_FONT_PX` в `js/configurator.js`). Если надпись всё равно шире площадки, шрифт дополнительно уменьшается по ширине.
- Надпись стоит в одной точке на всех формах (эталон — круг): центр на 248 px от верха картинки, ширина площадки 150 px (`--ty` и `--tw` у `.tag` в `css/styles.css`, значения в пикселях исходных превью).

## Цены и форма заказа

- Цена зависит только от формы: круг — от 990 ₽, сердечко — от 1 190 ₽, косточка — от 1 490 ₽. Значения лежат в `data-price` у радиокнопок «Форма» в `index.html`, текст «от X ₽» собирает `js/configurator.js`. Точную сумму называет менеджер.
- Кнопка «Заказать» (`data-order-open`) открывает `<dialog id="order">`: панель выезжает сверху, поля «ФИО» и «Контакты» обязательные, ниже чекаут (форма, цвет, текст, цена). Выбор берётся из `window.MetkaConfigurator.getState()`.
- После отправки панель закрывается, в правом верхнем углу на 5 секунд появляется уведомление (`#toast`). Время — `TOAST_MS` в `js/order.js`.
- Знак ₽ есть только в подмножестве шрифта latin-ext, поэтому подключён отдельный файл `assets/fonts/golos-text-latin-ext-600-normal.woff2` (в `@font-face` ограничен символом U+20BD).

## Прочее

- Две кнопки на главной всегда одной ширины (`.hero__actions` в `css/styles.css`); если в ряд не помещаются, встают друг под друга той же ширины.
- «Смотреть ещё» в галерее ведёт на https://www.threads.com/@metka.x в новой вкладке.
- Неразрывные пробелы после «с» и «в» в первом экране заданы как `&nbsp;` в `index.html`.
